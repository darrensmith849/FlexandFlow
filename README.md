# Flex & Flow

Premium one-page marketing site for **Flex & Flow** — a mindful stretch and mobility class by Christina Ribeiro.

## Stack

- Next.js 15 (App Router) + React 19
- Tailwind CSS 4
- lucide-react
- TypeScript

## Local development

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Deploy

Pushing to `main` triggers an automatic deploy on Vercel.
